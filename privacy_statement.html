BrailleKeyboard Privacy Statement

Privacy Overview

  • BrailleKeyboard has no network access.
  • BrailleKeyboard does not access the disk, except to read an optional configuration file when it starts up.
  • BrailleKeyboard only remembers the last three braille glyphs for the purposes of expanding contractions, and has no understanding of the input beyond this very limited logic.
  • BrailleKeyboard does not, by default, log any keystrokes. The user can enable this for the purposes of debugging by altering the log level in the optional configuration file to DEBUG.
  • When DEBUG logging is enabled, logging is written only to the console. Any further distribution requires the user to manually copy the console output.
  • It is not recommended to enable DEBUG logging except when specifically investigating a problem. When debugging, non-sensitive input should be used whenever possible.

BrailleKeyboard Privacy Statement

Privacy Overview

  • BrailleKeyboard has no network access, except that used by a networked voice, if selected. The voice is provided by Google's TTS engine
  • BrailleKeyboard only accesses local storage to save persistent settings.
  • BrailleKeyboard only remembers the last six braille glyphs for the purposes of expanding contractions, and has no understanding of the input beyond this very limited logic.
  • BrailleKeyboard does not log any keystrokes.
